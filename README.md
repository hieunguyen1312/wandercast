# WanderCast – AI lữ hành podcast

Ứng dụng web: AI agent bay và tự đi dạo 360° (Street View) khắp thế giới, hai host kể chuyện kiểu podcast.
32 tour có sẵn (20 tiếng Việt, 12 tiếng Anh), hoặc tự tạo tour mới bằng Gemini.

Mở: https://hieunguyen1312.github.io/wandercast/  (dùng Microsoft Edge để có giọng tiếng Việt tự nhiên)

Dữ liệu bản đồ: Esri World Imagery, OpenStreetMap (định tuyến đi bộ), Google Street View (ảnh 360°).
